## Key architectural notes to remember

1. **`AuthHandlerContext.encryptionProvider` is OPTIONAL** in the interface (T06b deviation). Production paths always set via `bootPhase2`. Read-site consumers use `!` non-null assertion. If you want to make it required, you'll need to update ~18 test fixtures that construct context literals (deferred to keep T06b's touch set bounded).

2. **HMAC labels are load-bearing strings** — appear in multiple places, MUST stay exact:
   - `"mcc-fingerprint-v1"` (computeKeyFingerprint)
   - `"mcc-audit-pseudonym-v1"` (user_id_hash in audit metadata — currently inline in T09; refactor to `src/security/audit-pseudonym.ts` helper in T12b)

3. **SQL prefix matching uses `GLOB 'enc:v[0-9]*:*'`** — never `LIKE 'enc:v_:%'` (single-char `_` wildcard misses `enc:v10:`). T06a's grep audit confirms zero `LIKE` left.

4. **AAD format is length-prefixed binary**: `u8(0x01) || u16be(len_org)||org || u16be(len_col)||col || u16be(len_user)||user`. Test #11 in `envelope-encryption.test.ts` is the forcing function. Do not change.

5. **Wire format pinned via deterministic vector** (`envelope-encryption.test.ts` test #13). If this test breaks, the storage format changed and existing rows are unreadable.

6. **`BootValidationError` lives in `src/boot-encryption.ts`** and is re-exported from `src/boot.ts` to preserve identity for 15+ existing consumers.

7. **Bun preserved**: zero native deps added; everything uses `node:crypto`. Tests run under Node (vitest); Bun runtime untested in CI (Open Q from V1 plan).
